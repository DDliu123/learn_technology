# 阶段 1 · 第 1 课：HTML 结构与语义化

目标：写出一个结构正确、内容完整的网页骨架（个人学习主页）。时长约 1.5 小时。

---

## 1. 浏览器的三件事

| 技术      | 负责      | 类比    |
| ------- | ------- | ----- |
| **HTML** | 有什么内容、什么结构 | 骨架   |
| **CSS**  | 长什么样    | 皮肤穿搭 |
| **JS**   | 能做什么交互  | 肌肉动作 |

本课只做 HTML：一个"难看但结构正确"的页面。第 2 课用 CSS 变好看。

浏览器只认这三种语言 —— 这就是为什么后端换成 Python，**前端仍必须是 JS**：浏览器里跑不了 Python。

---

## 2. 文档骨架

```html
<!DOCTYPE html>          <!-- 声明 HTML5，必须第一行 -->
<html lang="zh-CN">      <!-- 语言：影响翻译提示、SEO、屏幕阅读器 -->
  <head>                 <!-- 给浏览器和搜索引擎看的元信息，不显示 -->
    <meta charset="UTF-8" />                              <!-- 防中文乱码 -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />  <!-- 移动端必备 -->
    <title>页面标题</title>
  </head>
  <body>                 <!-- 用户看到的部分 -->
  </body>
</html>
```

`viewport` 漏写 = 手机上页面被整体缩小，这是新手最常见的移动端 bug。

## 3. 语义化标签（重点）

| 标签                              | 含义      |
| ------------------------------- | ------- |
| `<header>`                      | 页头      |
| `<nav>`                         | 导航      |
| `<main>`                        | 主体（每页仅一个） |
| `<section>`                     | 一块主题内容  |
| `<article>`                     | 独立可转载的内容（如一篇笔记） |
| `<aside>`                       | 侧边栏    |
| `<footer>`                      | 页脚      |

对比：

```html
<div class="header">我</div>     <!-- ❌ 全是 div，人看不懂机器更看不懂 -->
<header>我</header>               <!-- ✅ 一眼知道是页头 -->
```

三个收益：SEO（搜索引擎知道哪块是正文）、无障碍（屏幕阅读器可跳转）、**AI 协作**（你让 AI 改"导航栏"，它靠语义标签能精确定位）。

---

## 4. 常用标签

| 标签                          | 作用             |
| --------------------------- | -------------- |
| `<h1>`–`<h6>`               | 标题层级，每页一个 h1  |
| `<p>`                       | 段落            |
| `<a href="url">`            | 链接            |
| `<img src="" alt="">`       | 图片，**alt 必写**（无障碍 + 加载失败提示） |
| `<ul><li>` / `<ol><li>`     | 无序/有序列表       |
| `<strong>` / `<em>`         | 加粗/斜体（有语义）    |
| `<table>` + `thead/tbody/tr/th/td` | 表格（只用于真正的表格数据） |
| `<form>` `<input>` `<button>` | 表单（阶段 3 实战） |
| `<div>` / `<span>`          | 无语义容器：div 换行布局，span 包裹行内文字 |

---

## 5. 属性与路径

| 属性      | 用途                            |
| ------- | ----------------------------- |
| `class` | 样式钩子，**可重复**（多个元素共用）          |
| `id`    | 唯一标识，**页面内唯一**，可做锚点 `#about` |
| `href`  | 链接目标：网页、文件、`#锚点`、`mailto:`   |
| `src`   | 资源路径（图片、脚本）                   |
| `alt`   | 图片替代文字                        |

路径：`about.html` 同级、`pages/about.html` 下级、`../` 上级、`https://` 绝对地址。

## 6. 工具

| 工具                       | 用法                                  |
| ------------------------ | ----------------------------------- |
| Emmet                    | 空 html 文件里输入 `!` 按 Tab，瞬间生成完整骨架    |
| `ul>li*3>a` + Tab        | 一次生成 3 个带链接的列表项                     |
| **Live Server**（已装）      | 右键 HTML → Open with Live Server，保存自动刷新 |
| `python -m http.server 8000` | 无插件时的本地预览，访问 `localhost:8000`  |

双击 html 用浏览器打开（`file://`）也能看，但部署前必须用 Live Server（`http://`）验证，两者在资源加载上有差异。

## 8. 常见坑

| 现象               | 原因                          |
| ---------------- | --------------------------- |
| 中文乱码             | 缺 `<meta charset="UTF-8">`  |
| 手机上字特别小          | 缺 `viewport`                |
| 改了没生效            | 浏览器缓存：`Ctrl+F5` 强制刷新        |
| 表格布局被滥用          | 表格只放数据，页面布局交给 CSS（第 2 课）    |
