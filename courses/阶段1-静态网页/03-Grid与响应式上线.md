## 1. Flex 还是 Grid

| 场景             | 用什么   | 原因                    |
| -------------- | ----- | --------------------- |
| 一排/一列元素的排列     | Flex  | 一维：只管一个方向             |
| 多行多列的整体版式      | Grid  | 二维：同时管行和列             |
| 卡片墙、图库、后台仪表盘   | Grid  | 行列都要对齐                |
| 导航栏、按钮组、居中     | Flex  | 内容尺寸不定，按内容伸缩更好        |

判断口诀：**先想这是「一条线」还是「一张表」**。

## 2. Grid 核心

```css
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 16px;
}
```

这一行值，`minmax(220px, 1fr)` 表示每列最窄 220px、最宽占满剩余；`auto-fit` 自动算能放几列：

| 屏幕          | 结果     |
| ----------- | ------ |
| 宽 900px     | 3 列    |
| 宽 500px     | 2 列    |
| 宽 400px     | 1 列    |

**不需要写一行媒体查询就完成了响应式** —— 这是 Grid 相对 Flex 的最大优势。

其他常用：`grid-template-columns: 1fr 2fr`（两侧比例）、`grid-column: span 2`（某张卡占两列）。

## 3. 媒体查询

```css
@media (max-width: 640px) {   /* 屏幕 ≤640px 时才生效 */
  ...
}
```

| 写法            | 含义                |
| ------------- | ----------------- |
| `max-width`   | 桌面优先：针对小屏打补丁（新手友好） |
| `min-width`   | 移动优先：先写手机版再增强（工程推荐） |

本课用 `max-width`；阶段 4 接 Tailwind 后按移动优先写。

**流式字号**（很多场景替代媒体查询）：

```css
font-size: clamp(1.5rem, 5vw, 2rem);  /* 最小 / 随视口 / 最大 */
```

## 5. 部署：GitHub Pages

Pages 是从仓库直接发布静态网站的免费服务。它只认两个位置：**仓库根目录** 或 **`/docs` 目录**。

因为仓库里同时放着课件和站点代码，根目录会很乱，所以统一把站点放进 `docs/` —— 这就是刚才 `git mv` 的原因。

**开启步骤**（仓库 Settings → Pages，或用 gh）：

```bash
git add -A && git commit -m "feat: xxx" && git push   # 先确保改动已推送
# Settings → Pages → Build and deployment
# Source: Deploy from a branch
# Branch: main / docs → Save
```

等 1–3 分钟，访问 `https://<用户名>.github.io/<仓库名>/` 。

| 平台           | 适用          | 备注                    |
| ------------ | ----------- | --------------------- |
| GitHub Pages | 纯静态页（本阶段）   | 免费、零配置，和仓库天然一体         |
| Vercel       | React 等需构建的项目 | 阶段 4 起使用，push 即自动部署   |

铁律：**每次改动先 `git add` → `commit` → `push`，在线站点才会更新**。改了本地文件但没推送，线上不会变。

## 6. 移动端自查清单

在浏览器里按 `F12` → 点手机图标（设备模拟），检查：

- [ ] 标题没被截断，字号合适
- [ ] 导航没被挤成一团或出横向滚动条
- [ ] 表格能横向滚动，没有撑破容器
- [ ] 页面**没有出现左右横向滚动条**（最常见问题）
- [ ] 所有链接点得到（触摸目标足够大）
