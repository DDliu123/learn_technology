## 3. uv 常用命令

uv 是 Rust 写的 Python 环境与包管理器，替代 `pip` + `venv` + `pyenv`，速度快 10–100 倍。

| 命令                                          | 作用                               |
| ------------------------------------------- | -------------------------------- |
| `uv init 项目名`                               | 建项目骨架（自动生成 pyproject、.gitignore） |
| `uv run 文件.py`                              | 自动建虚拟环境并运行                       |
| `uv add 包名` / `uv remove 包名`                | 加/删依赖（自动写 pyproject + 锁版本）       |
| `uv sync`                                   | 按 `uv.lock` 装全部依赖（换机器时必做）        |
| `uv python list` / `uv python install 3.13` | 管理 Python 版本                     |
| `uv tree`                                   | 看依赖树                             |

关键认知：**不再手动 `python -m venv` + `pip install`**。`uv run` 会自动处理环境，你只管写代码。

## 4. 实操：跑通第一个程序（已验证）

```bash
uv init hello-uv        # 生成骨架
cduv
uv run hello-uv         # 输出：Hello from hello-uv!
uv add rich             # 装依赖，自动写入 pyproject + uv.lock
```

生成的文件：

| 文件                | 含义                            |
| ----------------- | ----------------------------- |
| `pyproject.toml`  | 项目身份证：名字、依赖、Python 版本要求       |
| `uv.lock`         | 锁死每个包的精确版本，保证别人装出来一致（须提交 git） |
| `.python-version` | 本项目用的 Python 版本               |
| `.venv/`          | 虚拟环境，**不提交 git**（uv 已自动忽略）    |
| `src/hello_uv/`   | 源码目录（uv 默认 src 布局）            |

注意：外层已有 git 仓库时用 `uv init --no-git`，避免嵌套仓库。
