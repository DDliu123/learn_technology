> 文件：`deps.py`（新增，解决 auth↔store 循环导入）、`store.py`、`app.py`

## 1. 把「当前是谁」变成一个参数

```python
# deps.py
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")

def get_current_user(token: str = Depends(oauth2_scheme)) -> User:
    username = decode_token(token)
    if username is None:
        raise HTTPException(401, "登录已失效，请重新登录")
    user = get_user(username)
    if user is None:
        raise HTTPException(401, "登录已失效，请重新登录")
    return user
```

路由里只要多声明一个参数：

```python
@app.get("/links", response_model=list[ShortLink])
def links(search: str | None = None, current_user: User = Depends(get_current_user)):
    return list_links(search=search, owner=current_user.username)
```

FastAPI 在调用路由**之前**完成：取 `Authorization` 头 → 解 JWT → 查库 → 注入 User。
校验失败直接 401，**路由函数根本不会执行** —— 不用在每个接口里重复写校验代码。

## 2. 归属隔离：owner 字段 + 每个查询都带上它

`ShortLink` 增加 `owner: str`（建索引），创建时**从 token 里取**，不信任请求体：

```python
def shorten(req: ShortenRequest, current_user: User = Depends(get_current_user)):
    return create_link(req, owner=current_user.username)   # ← 不是 req 里传的
```

| 操作 | 隔离做法 |
|---|---|
| 列表 | `.where(ShortLink.owner == owner)` |
| 统计 | 查到但 `owner != 自己` → 返回 None → **404** |
| 删除 | 查到但 `owner != 自己` → 抛 `NotOwnerError` → **403** |
| 跳转 | **不校验** —— 公开 |

**为什么「不信任请求体里的 owner」**：如果 owner 从 JSON 里读，任何人都能伪造成别人的用户名。

---

## 3. 403 vs 404：什么时候该暴露「它存在」

| 场景 | 返回 | 理由 |
|---|---|---|
| 删除别人的短链 | **403** | 你确实有权限访问这个接口，只是这条资源不是你的 → 「禁止」语义准确 |
| 查看别人的统计 | **404** | 不想让别人知道「这个短码存在」→ 装作不存在 |

取舍原则：**能操作但不能碰 = 403；连存在与否都不该让人知道 = 404**。

---

## 4. 产品取舍：跳转必须公开

短链的核心价值是「任何人点都能跳转」。如果 `/{code}` 也要登录，产品就废了。
所以本项目分区：

| 接口 | 是否要登录 |
|---|---|
| `GET /{code}`（跳转） | **公开** |
| `GET /health`、`GET /` | 公开 |
| `/register`、`/token` | 公开（不然没法注册登录） |
| `GET /links`、`POST /shorten`、`GET /stats/{code}`、`DELETE /{code}` | **必须登录 + 只能自己的** |

## 5. 本机踩坑（本课真实踩到）

| 现象 | 解法 |
|---|---|
| `ImportError` 循环导入 | auth 要查用户（import store）、store 要哈希密码（import auth）。**拆模块**：`auth.py` 只做加密不碰库，`deps.py` 同时 import 两边 |
| 加了 `owner` 字段，查询报 `no such column: short_link.owner` | `create_all` 不改老表结构（阶段 6 迁移问题，**这次真踩到了**）；开发期删掉 `shortlink.db` 重建 |
| 老测试全部 401 | 阶段 7 起管理接口要 token，测试必须先注册登录再操作 |
