## 2. 基础类型

| 类型      | 例子                | 说明                |
| ------- | ----------------- | ----------------- |
| `int`   | `42`              | 整数                |
| `float` | `68.0`            | 小数（金额用它能算除法）      |
| `str`   | `"Netflix"`       | 字符串，单双引号都行        |
| `bool`  | `True` / `False`  | 首字母大写             |
| `None`  | `None`            | 空值，不是 0 也不是 ""    |
| `list`  | `[68.0, 58.0]`    | 有序可变，取值 `a[0]`    |
| `dict`  | `{"name": "Netflix"}` | 键值对，取值 `d["name"]` |

Python 是动态语言，变量不用声明类型；但**函数签名上要写类型注解**，这是给人和 AI 看的契约。

## 3. f-string 与格式化

```python
name, price = "Netflix", 68.0
print(f"{name} 每月 {price} 元")           # 嵌入变量
print(f"¥{price:,.2f}")                   # 千分位 + 两位小数 → ¥68.00
print(f"{name:<16}|")                     # 左对齐占 16 字符宽
print(f"{name:>10}|")                     # 右对齐占 10 字符宽
```

对齐语法是让 CLI 输出变成整齐表格的关键：`{变量:<宽度}` 左对齐、`{变量:>宽度}` 右对齐。

## 4. 列表与字典高频操作

| 操作             | 写法                                 |
| -------------- | ---------------------------------- |
| 求和             | `sum(...)`                         |
| 最大值/自定义规则     | `max(list, key=lambda x: x["price"])` |
| 遍历带序号          | `for i, x in enumerate(list):`     |
| 字典取值带默认值       | `d.get("k", 默认值)`                 |
| 分组惯用写法         | `groups.setdefault(k, []).append(x)` |
| 判断元素是否存在       | `if x in list:`                    |

**列表推导式**（见到要认得，能写更好）：

```python
prices = [sub["price"] for sub in subs]              # 提取所有月费
expensive = [s for s in subs if s["price"] > 100]    # 过滤出贵的
```

等价但更啰嗦的写法：for 循环 + append。推导式是 Pythonic 的标志。

## 5. 函数

```python
def monthly_cost(subs: list[dict]) -> float:      # 参数类型 + 返回值类型
    """月支出：一句话说清做什么。"""                      # docstring，AI 也读它
    return sum(sub["price"] for sub in subs)
```

规则：
1. **一个函数只做一件事**（`monthly_cost` 只算，`print_summary` 只打印）
2. 能复用就复用（`annual_cost` 直接调用 `monthly_cost * 12`）
3. 名字用「动词+名词」：`get_*` / `calc_*` / `print_*`
4. 别在函数里直接改外部变量，用 return 交出结果

## 7. 常见错误

| 报错/现象                       | 原因                          |
| --------------------------- | --------------------------- |
| `IndentationError`          | 缩进不一致，统一 4 个空格              |
| `KeyError: 'price'`         | 字典里没有这个键，检查拼写或改用 `.get()`   |
| `TypeError: str + float`    | 类型混算，先轉 `float(x)` 或 `str(x)` |
| 改了代码运行结果没变                  | 没保存，或 `uv run` 缓存了旧包（极少见，重启终端） |
| 中文输出乱码（Windows）             | 用 Git Bash 终端；文件保存为 UTF-8   |
