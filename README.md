# learn_technology

记录一名 AI 产品经理从 0 到 1 学做软件的完整过程。全程 AI 辅助编程，公开学习笔记。

## 路线

主线技术栈：**React（前端） + Python FastAPI（后端） + PostgreSQL**，约 26 周，每周 6–8 小时。
以「完成可运行产品」为单位推进，不做纯语法练习。详见 [学习路线-总览.md](./学习路线-总览.md)。
